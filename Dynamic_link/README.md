# Dynamic Link Gateway

Trạm chuyển tiếp link thông minh (Smart OS Fallback Router) cho các ứng dụng di động.

## 🚀 Cách Bật GitHub Pages
1. Tạo repository mới trên GitHub đặt tên là `dynamic_link` (hoặc tên tùy chọn).
2. Đẩy toàn bộ mã nguồn này lên nhánh `main`.
3. Vào **Settings** của Repository -> Chọn mục **Pages**.
4. Tại phần **Source**, chọn nhánh `main` và thư mục `/ (root)` -> Bấm **Save**.
5. Link chính thức sẽ có dạng: `https://samngoclinh.github.io/dynamic_link/<app_name>/`

## ➕ Cách Thêm App Mới Sau Này
1. Tạo một thư mục mới: ví dụ `app2/`.
2. Tạo file `index.html` và ảnh banner `og_banner.jpg` tương tự như mẫu trong thư mục `chess/`.
3. Sửa 2 biến `IOS_STORE_URL` và `ANDROID_STORE_URL` ở đầu file `index.html`.
